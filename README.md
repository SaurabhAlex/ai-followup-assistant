# AI Follow-up Assistant

A simple Python and FastAPI project that helps identify overdue customer follow-ups and generate personalized message drafts using AI.

## Features
- Identify overdue follow-ups.
- Prioritize customers.
- Generate AI-powered message drafts.
- Review messages before taking action.

## Tech Stack
- Python
- FastAPI
- Pydantic
- OpenAI API (planned)

## Getting Started

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   uvicorn app.main:app --reload
   ```

5. Open http://127.0.0.1:8000/docs to explore the API.
